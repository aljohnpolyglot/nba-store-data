Eurobasket Europe season recap archive

Each country folder contains its detected first-tier domestic league.
Europe/ contains EuroLeague, EuroCup, ABA League, and VTB United League.
Each recap stores the title, date, description, banner/image URL, source URL, and optional video URL.
Eurobasket Awards, weekly awards, All-Star items, domestic cups, and SuperCups are excluded.

The scraper uses IndexedDB checkpoints. Rerunning the same script resumes completed competition-seasons.
To erase the checkpoint, run: await resetEurobasketSeasonRecapCheckpoint()
